# github-playground
Repo latihan alur kerja GitHub: issue, branch, dan pull request

## Tujuan

Repo ini tempat berlatih alur kerja GitHub: membuat issue, bekerja di branch terpisah, lalu menggabungkannya lewat pull request.

## Alur Kerja

Buat branch baru, simpan perubahan sebagai commit, buka pull request, periksa diff-nya, lalu merge ke branch main.
